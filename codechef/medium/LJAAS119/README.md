## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-24T13:48:43.592Z  

```java
class Codechef
{
	public static void main (String[] args) 
	{
	    int sum =0;
	    for (int i =1;i<=10 ;i++ ){
	        sum = sum+i;
	    } 
	    System.out.println(sum);
	}
}

```
